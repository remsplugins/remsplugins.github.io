# Rems Plugins

Free audio plug-ins for macOS (VST3 / AU, Apple Silicon + Intel) and Windows (VST3, 64-bit).

- **Revolution** (coming soon, formerly Halcyon 1.3.0): wavetable synthesizer with 3,000 presets, eight skins, animated Normal-mode scenes, custom LFO shapes, Vital / Serum 2 import. Halcyon 1.3.0 stays available until then.
- **MixPilot 1.2.1**: assisted mixing and mastering (Track + Master), with an editable EQ, up to 12 free EQ bands and a resizable window.

Download page: https://remsplugins.github.io/
