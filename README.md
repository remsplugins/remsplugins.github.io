# Rems Plugins

Free audio plug-ins for macOS (VST3 / AU, Apple Silicon + Intel) and Windows (VST3, 64-bit).

- **Halcyon 1.2.0**: wavetable synthesizer with 2,041 presets, granular and spectral engines, Time Machine, Breed, Vital / Serum 2 preset import and skins.
- **MixPilot 1.0.2**: assisted mixing and mastering (Track + Master).

Download page: https://remsplugins.github.io/
