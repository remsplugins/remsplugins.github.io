# Rems Plugins

Free audio plug-ins for macOS (VST3 / AU, Apple Silicon + Intel).

- **Halcyon**: wavetable synthesizer with 2,041 presets, granular and spectral engines, Time Machine and Breed.
- **MixPilot**: assisted mixing and mastering (Track + Master).

Download page: https://remsplugins.github.io/
Downloads: [Halcyon](downloads/Halcyon-1.0.0-macOS.zip) · [MixPilot](downloads/MixPilot-1.0.0-macOS.zip)
